# 미핑(MiPing) · 약관 · 개인정보처리방침

미핑 앱의 **개인정보처리방침**과 **서비스 이용약관** 정적 사이트.
색·타이포는 앱 팔레트(`app_colors.dart` / `app_typography.dart`)를 그대로 옮겨 톤을 맞췄다.

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 두 문서로 가는 목록 |
| `privacy.html` | 개인정보처리방침 |
| `terms.html` | 서비스 이용약관 |
| `style.css` | 공통 색·레이아웃 |

## 배포

Vercel에 연결돼 있어 **`main` 브랜치에 push하면 자동 배포**된다.

로컬 미리보기:

```bash
python -m http.server 8000   # http://127.0.0.1:8000
```
